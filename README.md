# Sales Performance Dashboard

An interactive **Sales Performance Dashboard** created using Tableau to analyze e-commerce sales data.

## Tools Used

* Tableau
* MySQL
* CSV

## Key Analysis

* Total Revenue
* Total Quantity Sold
* Total Orders
* Revenue by Product
* Revenue by Category
* Quantity Sold by Product

## Workbook

`Sales_Performance_Dashboard.twbx`

## Project Objective

To transform sales data into interactive visualizations and generate meaningful business insights using Tableau.
